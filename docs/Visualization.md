# Visualization
Now that the data is stored in Eventhouse you can utilize multiple options to visualize the data.

## Power BI
You can [Visualize data in a Power BI report](https://learn.microsoft.com/en-us/fabric/real-time-intelligence/create-powerbi-report). 

## RTI Dashboard
[Real-Time Dashboards](https://learn.microsoft.com/en-us/fabric/real-time-intelligence/dashboard-real-time-create) allow you to visualize data from a KQL Database.

## Grafana
There is an existing data source in [Grafana](https://learn.microsoft.com/en-us/azure/data-explorer/grafana?tabs=azure-managed-grafana) that allows you to connect to and visualize data in a KQL database.

## KQL Queryset
[KQL Querysets](https://learn.microsoft.com/en-us/fabric/real-time-intelligence/kusto-query-set?tabs=kql-database) can be used to explore and visualize you data. Along with pin visuals to a Power BI Report or RTI Dashboard.

## SDKs
There is a fully supported [REST APIs](https://learn.microsoft.com/en-us/kusto/api/rest/?view=azure-data-explorer&preserve-view=true) along with SDKs for [.NET](https://learn.microsoft.com/en-us/kusto/api/netfx/about-the-sdk?view=azure-data-explorer), [Python](https://learn.microsoft.com/en-us/kusto/api/python/kusto-python-client-library?view=azure-data-explorer), [R](https://learn.microsoft.com/en-us/kusto/api/r/kusto-r-client-library?view=azure-data-explorer), [Java](https://learn.microsoft.com/en-us/kusto/api/java/kusto-java-client-library?view=azure-data-explorer), [Node](https://learn.microsoft.com/en-us/kusto/api/node/kusto-node-client-library?view=azure-data-explorer), [Go](https://learn.microsoft.com/en-us/kusto/api/golang/kusto-golang-client-library?view=azure-data-explorer), and [PowerShell](https://learn.microsoft.com/en-us/kusto/api/powershell/powershell?view=azure-data-explorer&tabs=user) that allow you to query data.
