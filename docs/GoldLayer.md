## Gold Layer
The Gold Layer is where data is optimized for visualization needs while still maintaining the real-time aspect of your data.

### Aggregate Views
Aggregate views are computed as data arrives via Materialized Views, providing:
- Real-time aggregations
- Efficient query performance
- Cost-effective storage

### Latest Value Views
Latest value views are maintained via Materialized Views to:
- Provide quick access to the most recent values
- Support real-time dashboards
- Enable efficient monitoring
